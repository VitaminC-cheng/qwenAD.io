# 大学四年，一问到底

一个面向大学生的千问互动广告页面。页面以“100 万 Token 能装下多少大学生活”为叙事线，串起大一复习、大二协作、大三资料调研、大四答辩作品集等场景。

## 预览

这是一个纯静态页面，不需要构建步骤。直接用本地静态服务打开即可：

```bash
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

## 页面内容

- 封面：千问学习管家入口和 100 万 Token 概念
- 大一：复习资料整理、课堂录音转写翻转卡片
- 大二：小组协作与成果汇报讲稿翻转卡片
- 大三：论文、访谈、问卷、代码资料的复杂问题处理
- 大四：毕业待办清单、答辩逻辑与作品集表达
- 创意页：图像与视频额度、视觉作品生成场景
- 结尾：AI 使用原则与行动入口

## 主要交互

- 侧边时间轴滚动进度
- 点击式翻转卡片
- 待办清单点击完成状态
- 全部完成后的烟花动画
- 任务卡片、流程卡片和电池充能互动

## 技术栈

- HTML / CSS / JavaScript
- ECharts 和 echarts-wordcloud CDN
- 本地字体资源：霞鹜文楷、破晓像素体、秋鸿楷
